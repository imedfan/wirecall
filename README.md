# Wirecall

Частный видеозвонок для двоих. Сын и мама открывают одну ссылку: сервер только знакомит браузеры, картинка и звук идут напрямую между ними. Разговор не записывается, аналитики нет.

Это не телефонный звонок. Safari не держит связь в фоне, как приложение. Если заблокировать экран или уйти в другое приложение, камера и звук остановятся, пока человек не вернётся на страницу. Иконка «На экран Домой» — ярлык, не входящий вызов.

## Как пользоваться

1. Один человек открывает сайт и нажимает **Создать ссылку**.
2. Ссылку отправляет второму. В комнате только два участника.
3. Оба нажимают **Войти в звонок** и разрешают микрофон и камеру. Без камеры звонок остаётся со звуком.
4. Круглые кнопки внизу экрана: микрофон, камера, поворот камеры (если камер больше одной), связь (диагностика), завершить. На Mac работают клавиши `M` (микрофон) и `V` (камера). Нажатие на картинку собеседника переключает «весь кадр» и «на весь экран».
5. Если звук собеседника не играет, на экране будет **Включить звук**.

Ссылка действует 14 дней с последней активности и продлевается, пока кто-то в комнате. Секрет комнаты — сама ссылка. В коде нет семейных паролей.

Пока TURN не настроен, на экране прямо сказано: работает только прямое соединение. Если сеть не пускает его, звонок может не собраться.

## Локальный запуск

Нужен Node.js 22.

```bash
npm ci
npm run build
npm run dev
```

Сайт откроется на `http://127.0.0.1:8787`. Для `localhost` браузер считает контекст защищённым, камера доступна. С другого телефона в той же сети этот адрес не подойдёт: нужен HTTPS. Для проверки с настоящих iPhone сайт нужно разместить.

Файл `.dev.vars` не коммитится. Пример пустых значений — `.dev.vars.example`.

## Проверки на этой машине

GitHub Actions и других workflow в репозитории нет. Команды ниже запускаются локально:

```bash
npm run check
npm run test:browser
```

`npm run check` — lint, проверка типов, модульные тесты и сборка клиента.

Модульные тесты проверяют контроллер качества (шаг вниз, гистерезис, пропуски `getStats`, возврат по одному уровню), допуск ровно двух участников, возобновление своей сессии, отказ чужому токену, очистку зависшего участника, изоляцию комнат, лимит создания, происхождение запроса, размер сообщений и порядок кодеков H264, затем VP8, без VP9 и AV1.

Браузерный тест поднимает локальный `wrangler dev` и два настоящих `RTCPeerConnection` в Chromium с поддельной камерой. Перед первым запуском нужен `npx playwright install chromium`. Снимки экрана пишутся в `test-results/artifacts` (или в `WIRECALL_ARTIFACTS`). Он проверяет, что картинка пошла, третий участник получает отказ, вышедший освобождает место, завершивший звонок и вошедший снова соединяется в любой роли, чужой сайт не создаёт комнату, а страница без камеры показывает понятную ошибку. В консоль браузера не должны попадать SDP и токен возобновления.

Эти тесты не измеряют качество сети между Россией и другой страной и не заменяют проверку на iPhone 12 Pro, iPhone 15 и MacBook.

## Размещение на Cloudflare

Цель — один Worker со статикой и SQLite Durable Object на комнату. WebSocket комнаты гибернирует: объект не держится в памяти, пока нет сообщений. Медиа через Worker не ходит.

Бесплатный план Workers умеет SQLite Durable Objects. По [тарифам Durable Objects](https://developers.cloudflare.com/durable-objects/platform/pricing/) на 18 октября 2026 у Free такие суточные пределы: 100 000 запросов, 13 000 GB-s длительности, 5 млн чтений строк, 100 000 записей строк и 5 ГБ SQLite суммарно. Превышение на Free даёт ошибку, а не счёт. Workers Paid и любые подписки включать не нужно. Платный план сам по себе ничего не включает автоматически сверх того, что вы включите, но этот проект его не требует и не включает.

Входящие сообщения WebSocket тарифицируются с коэффициентом 20:1. Протокольные ping не будят объект. Сигнальных сообщений у двоих немного. Частые будильники во время звонка не ставятся: срок комнаты — один alarm.

Родитель входит в уже подключённый аккаунт сам. Агент учётные данные не использует.

```bash
npm ci
npm run build
npx wrangler login
npx wrangler deploy
```

`wrangler deploy` выкладывает Worker и файлы из `dist/client`. Отдельный Pages-проект не нужен. После деплоя адрес будет вида `https://wirecall.<account>.workers.dev`, если не привязан свой домен. Свой домен добавляется в панели Cloudflare у этого Worker. Оба адреса уже с HTTPS.

Если адрес `workers.dev` публичный, имеет смысл задать ключ создания комнаты. Вход по уже выданной ссылке ключ не спрашивает.

```bash
npx wrangler secret put CREATE_GATE
npx wrangler secret put LIMIT_HASH_SALT
```

`CREATE_GATE` — длинная случайная строка, не пароль от семьи в репозитории. Сайт один раз спросит её перед созданием ссылки. `LIMIT_HASH_SALT` нужен, чтобы в лимите не лежал сырой IP. Без него используется встроенная постоянная строка.

Лимиты создания: 30 комнат в час с одного адреса и 200 в сутки на весь сайт. В комнате не больше двух живых участников и не больше четырёх сокетов.

Секреты в `wrangler.jsonc` не записаны. Журналы пишут тип события, размер и короткий хеш комнаты, без SDP, ICE, токена и ключей.

## TURN

По умолчанию TURN выключен. Браузер получает только `stun:stun.cloudflare.com:3478`. По [FAQ Realtime](https://developers.cloudflare.com/realtime/turn/faq/) этот STUN бесплатный и без лимита. STUN не пропускает через себя звук и видео. Он только помогает узнать внешний адрес. Симметричный NAT, часть мобильных сетей и жёсткие фильтры прямое соединение режут. Тогда звонок без TURN не соберётся. Интерфейс говорит об этом открыто.

Чтобы включить релей Cloudflare, ключ TURN создаётся в панели Realtime. API-токен этого ключа остаётся на сервере. Браузеру уходит только короткоживущий логин, и только внутрь уже открытой комнаты. Отдельного публичного адреса «выдай TURN» нет.

```bash
npx wrangler secret put TURN_KEY_ID
npx wrangler secret put TURN_API_TOKEN
```

Потом в `wrangler.jsonc` у `TURN_ENABLED` ставится `"true"` и снова выполняется `npx wrangler deploy`. Локально то же пишется в `.dev.vars`, который не коммитится. Срок выданных данных — сутки, чтобы долгий звонок и перезапуск ICE не упирались в просроченный логин. Сервер обновляет их раз в 50 минут и отдаёт свежие при каждом входе собеседника. Порт 53 отбрасывается.

Формулировки Cloudflare расходятся, поэтому нулевой счёт обещать нельзя:

- страница [TURN](https://developers.cloudflare.com/realtime/turn/) (25 сентября 2026) пишет, что TURN бесплатен вместе с Realtime SFU, а иначе стоит $0.05 за ГБ исходящего трафика;
- [FAQ](https://developers.cloudflare.com/realtime/turn/faq/) и [тариф Realtime](https://developers.cloudflare.com/realtime/sfu/platform/pricing/) говорят о первых 1000 ГБ в месяц бесплатно, общими для SFU и TURN, затем $0.05/ГБ.

Wirecall SFU не использует. Жёсткого потолка расходов в документации нет. Перед включением TURN посмотрите оценку в панели. Для двоих 720p даже часть часа через релей — это гигабайты.

## Что важно для Safari

Стартовое видео — около 720p и 30 кадров. Выше, до потолка 1080p, качество поднимается только если несколько хороших замеров подряд и браузер сообщил запас исходящей полосы. При потерях или большой задержке потолок снижается, при сильной деградации остаётся звук. Кодеки: H264 с `packetization-mode=1`, затем VP8. VP9 и AV1 не запрашиваются. Аудио — Opus, если браузер его отдаёт. Эхоподавление, шумоподавление и автоуровень включаются только если `getSupportedConstraints` их перечисляет. Тяжёлых фильтров нет.

Поля `getStats`, которых нет в Safari, в диагностике показаны как «неизвестно»: маршрут прямое/релей, RTT, потери, кадры, размер, битрейт.

Пока нет удалённого SDP, ICE-кандидаты копятся локально. Offer создаёт только один участник; вошедший заново получает ту роль, которой нет у оставшегося.

Восстановление идёт по шагам. Если соединение не собралось за 8 секунд или ICE оборвался, предлагающая сторона дважды перезапускает ICE, затем комната пересобирает соединение у обоих с новыми ICE-серверами (вход по токену возобновления). Вторая сторона ждёт дольше и делает то же сама, если первая молчит. После четырёх пересборок подряд показывается кнопка «Переподключить». Сигнальный сокет проверяется ping/pong: без ответа за 10 секунд (4 секунды после смены сети или возврата на вкладку) он открывается заново. Попытки вернуть сокет идут около пяти минут. После возвращения на вкладку оборванные дорожки запрашиваются снова и подменяются через `replaceTrack`. Screen Wake Lock включается только если браузер его умеет.

## Чеклист на настоящих телефонах

Проверяет человек с устройствами. Автотест этого не закрывает.

- [ ] iPhone 12 Pro, Safari: сайт по HTTPS, не из встроенного браузера мессенджера.
- [ ] iPhone 15, Safari, и отдельно MacBook Pro в Safari.
- [ ] Создать ссылку на одном устройстве, открыть на втором, оба нажать «Войти».
- [ ] Слышно речь без постоянных провалов. Своё эхо не мешает.
- [ ] Картинка лица узнаваемая при спокойной сети. При плохой сети остаётся звук, а не молчание.
- [ ] Выключить и включить микрофон и камеру. Переключить камеру на iPhone.
- [ ] Заблокировать iPhone на полминуты, разблокировать, вернуться в Safari: картинка и звук восстанавливаются кнопкой или сами. Ожидать фоновый звонок не нужно.
- [ ] Переключить Wi‑Fi и сотовую сеть на одном телефоне. Связь либо жива, либо сама пробует восстановиться, либо честно пишет, что нужно войти снова.
- [ ] В диагностике маршрут «прямое» или «релей», а неизвестные цифры не подменены нулями.
- [ ] Третий телефон с той же ссылкой видит, что комната занята.
- [ ] Запретить Safari камеру и микрофон, войти: есть текст, как открыть Настройки → Safari → Камера и Микрофон.
- [ ] Если прямое соединение между городами не собирается, не считать это поломкой кода, пока TURN сознательно не включён и не проверен.
